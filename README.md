# SAIPORT - Venkata Sai Mudde Portfolio

🌐 **Live Website:** [https://venkatasaimudde-cloud.github.io/SAIPORT/](https://venkatasaimudde-cloud.github.io/SAIPORT/)

Welcome to the personal developer portfolio of **Venkata Sai Mudde**, Artificial Intelligence and Data Science student at Ramachandra College of Engineering (RCEE).

## 🚀 Features
- **Modern Responsive Design**: Fully responsive layout tailored for mobile, tablet, and desktop displays.
- **Theme Switching**: Dark / Light mode toggle with persistent preferences.
- **Showcase Sections**: About, Achievements, Technical Skills, Featured Projects, and Education.
- **Contact & Socials**: Direct links to LinkedIn, GitHub, Instagram, and Gmail.
